# Imported Roblox sets (Creator Store -> Blender)

Use in a story: `"set": {"preset": "rbx", "rbx": "school_classroom", "at": [0, 0], "rot": 0}` (id, slug or any substring; optional `time`, `outdoor`, `ground`).
Python: `sets.rbx_set(id_or_tag, at=(0,0) studs, rot=deg, scale=1)` -> same dict as `sets.build` (supports/obstacles/bounds/info). The set footprint
centre lands on `at`, the floor on z = 0, 1 stud = 0.5 m. Solid pieces are registered in `assets.PLACED` as `<slug>_<group>_<k>`; every chair/sofa/bench
(a cluster holding an invisible Roblox Seat) is named `<slug>_seat_<k>` -> `{"sit": "school_classroom_seat"}` picks the nearest one.
Ceilings/roofs (big parts above 2.8 m) are dropped so the engine's lights and cameras work.

## Add a set (about 3 min each)
1. MCP `search_asset` (scope creator_store, priceFilter free, assetType Model), pick a model made of Parts (description says "N parts, no/few meshes/unions").
2. MCP `insert_asset` with `assetName imp_<id>`, `parentPath game.Workspace.SetImport` (InsertService:LoadAsset is "not authorized" for other creators).
3. Paste `tools/rbx_set_export.luau` into `execute_luau` (Edit): prints `RBXSET|id|n|json` lines to the Studio log. If the model has meshes, paste
   `tools/rbx_set_meshes.luau` (set ID) too. Delete the `imp_*` copies from SetImport afterwards.
4. `python tools/rbx_set_import.py fetch <id> <slug>` -> `assets/rbxsets/<id>_<slug>/` (scene.json, meshes/, textures/).
5. `python tools/rbx_set_sheet.py <slug>` for the evidence still.

`fetch` also runs `python tools/rbx_set_doc.py <slug>` automatically. Run that command without a slug to regenerate every plan and the sections below.
Plans use a stud grid, numbered solid footprints linked to exact engine names, seats in gold, sampled standing clearance in green,
and 3-5 standing spots checked with `space.World`. Green space and the spots are checked at yaw 0 on a one-stud grid; turns and routes need their own checks.
Use an exact name from a piece table in `walk: ["name"]`, `look: "name"`, or `shots.on: ["name"]`; use `sit: "name"` for a seat.
`walk` stops beside the piece. Look/shot anchors use the piece's base centre, as for preset furniture. For a transformed set, transform the documented spots too.

## Limits
- Unions: Studio does not expose their geometry (`AssetId` unreadable) -> bounding box with the union colour (trees in small_park are cubes).
- MeshParts without a cache hit become boxes (all 5 meshes in the 9 sets were found: Studio cache by time window, bounding box checked against MeshSize).
- SurfaceGui text is recorded in scene.json but not drawn; CornerWedge apex corner is a guess; SpecialMesh mesh origin is taken as the mesh origin.
- Decals/Textures: image via the public thumbnails API, tiled by StudsPerTile; Decal face orientation derived from the Roblox axes, not pixel-verified on a real decal.
- Roblox lights are recorded (`info['lights']`) but the engine's look.py lights the set; no Roblox sky/lighting.
- Solids: CanCollide, visible, bottom < 1.5 m; parts of one Model that overlap merge into one registry entry (walls and > 6 m parts stay separate); ground-like slabs are not solid.
  The classrooms' walls register as thin obstacles, so routing treats the room shell as walls; `info['bounds']` = whole set footprint (can be large: supermarket 70 x 43 m).
- Big sets (> 300 meshes/unions, e.g. gamer room 5856849861: 496 meshes, 238 unions) were skipped as too heavy for a first pass.
